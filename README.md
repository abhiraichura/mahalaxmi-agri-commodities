# Mahalaxmi Agri Contracts

Professional contract management system for agri-commodity brokers.

## Features

- **Contract Notes**: Create, view, edit, delete professional A4 contract notes
- **Three Copy Types**: Broker, Buyer, Seller (party order changes automatically)
- **Master Data**: Save parties and products once, reuse forever
- **GST Verification**: Auto-fetch company details from GSTIN
- **Brokerage Bills**: Auto-generated monthly bills with view + download
- **Digital Signature**: Upload signature that appears on every contract
- **Logo Upload**: Company branding on all documents
- **WhatsApp Sharing**: One-click share contracts and bills
- **PWA**: Install as native app on Android/iPhone
- **Offline Support**: Works without internet after first load
- **Firebase Backend**: Real-time sync, permanent storage, free tier

## Tech Stack

- React 18 + TypeScript + Tailwind CSS
- Firebase (Auth + Firestore)
- jsPDF (client-side PDF generation)
- Vite PWA (offline capability)
- Vercel Hosting (always online, free)
